# TetherSDK

Building **TetheredWorks** — a modular point-of-sale, inventory, and business-operations platform, built as a suite of focused apps and SDKs rather than one monolith.

**Live showcase:** [www.tetheredworks.com](https://www.tetheredworks.com)

## What's here

The repos under this org are the individual pieces of the TetheredWorks platform — scanning, inventory, checkout, and the business/admin tooling that ties them together. A few of the ones actively in development:

- **TetherScanner** — a Kotlin Multiplatform barcode/document scanning SDK (Android, iOS, and Desktop), with support for external hand-scanner hardware (Zebra CoreScanner SDK, plus universal keyboard-wedge/HID scanners) and real-time multi-device sync so a phone or tablet scan can show up live on a Desktop POS.
- **TetherInventory**, **TetherShop**, **TetherCartCheckout**, **TetherBusiness** — inventory, storefront, checkout, and business-management apps built on top of the same shared SDKs.
- **TetheredWorksWeb** — the web presence for the platform.

## Why this org's repos are private

The code here is proprietary and not open source. This org page exists so the work is visible and attributable even though the source isn't public — the [live showcase](https://www.tetheredworks.com) is the best way to see what's actually been built.
